# 本地语音

> **这是一份个人自用工具，只为我的一加 15R（OnePlus 15R）以及我自己的使用习惯设计和调优。** 它不是通用 Android 输入法，也不保证能在其他机型、ROM 或系统版本上正常工作。仓库里的 `minSdk 26` 只是工程编译配置，不代表这些系统版本已经实测。

用无障碍服务在当前输入框的光标处填入端侧识别结果：屏幕点亮且已解锁时，单击一加 15R 机身左侧独立键开始录音，再按一次停止并落字。它不替换系统键盘，也不会出现在「输入法」列表里。

本仓库不提供识别准确率、速度或内存占用方面的测试数据，因此也不做这类承诺。

---

## 项目定位与适用范围

- **它是什么**：安装在手机上的普通应用（免 Root）。主界面只负责检查权限、下载或导入模型、开关震动；真正听键和填字的是无障碍服务「本地语音服务」，录音时在屏幕左侧显示一个不可点击的状态小药丸（无障碍悬浮层，不是系统悬浮窗权限）。
- **它不是什么**：不是系统输入法（IME），不会抢焦点、也不会主动收起软键盘。源码里虽然使用了无障碍的 `flagInputMethodEditor`，那只是为了在 Android 13 及以上走 `AccessibilityInputConnection.commitText` 往已有光标写字，并不等于注册成输入法。
- **为谁而做**：只在我的一加 15R 上按自己的习惯使用。左侧独立键的键值（单击 `KEYCODE_781`）、小药丸紧贴左边缘并垂直落在屏幕高度约 22% 处，以及微信输入框的一个控件 ID，都是按这台机器上的使用方式写的，换机型或微信改版后可能失效。
- **仓库提供什么、不提供什么**：这里只有源码。不含模型权重、不含编译好的 APK，也不含我本机的配置或录音。

## 准备与使用

首次使用需要先完成三件事：**安装应用、打开必要权限、准备模型**。

1. 打开应用「本地语音」。主页有三张卡片：**运行状态**、**语音模型**、**震动反馈**。
2. 若「运行状态」显示未就绪，点卡片上的「去开启」：
   - 未开启无障碍时，会跳到系统无障碍设置，请打开「本地语音服务」。
   - 无障碍已开但尚未授权麦克风时，会请求麦克风权限。
3. 在「语音模型」卡片准备 SenseVoice 模型（二选一即可，且必须同时有词典 `tokens.txt`）：
   - 点某一行「SenseVoice INT8 · 轻量版」或「SenseVoice FP16 · 满血版」右侧的「直接下载」，或点底部的「在线直接下载并安装」再选版本。应用会先拉取 `tokens.txt`，再下载对应权重到应用私有目录下的 `sense-voice` 文件夹（文件名分别为 `model.int8.onnx` 与 `model.onnx`）。下载中可点「取消」。界面上标注的大约体积（INT8 约 228 MB、FP16 约 894 MB）只是应用里的提示，以实际下载为准。
   - 若不想在线下载，可点「从手机文件导入」，一次选择模型与 `tokens.txt`。导入时按文件名识别：带 `int8` 的 `.onnx` 会存为 `model.int8.onnx`，其他 `.onnx` 存为 `model.onnx`，文件名含 `tokens` 的存为 `tokens.txt`。
   - 「GitHub 页面 ↗」会在浏览器打开 sherpa-onnx 官方模型 Release 页，便于自行查看或另存文件，并不会自动安装。
4. 「震动反馈」可随时开关，只影响开始、结束录音时的微震，与识别无关。

之后的日常用法（源码里实际支持的操作）：

- 屏幕必须点亮且已解锁。熄屏、锁屏时按左侧独立键会被忽略；音量键和电源键也不会触发录音。
- **按一次左侧独立键开始录音**，左侧出现半透明小药丸；**再按一次停止，识别完成后写入当前光标**。若开了录音但没有有效语音，再按一次会静默结束。
- 小药丸只作状态提示，触摸会穿透，不会挡住底下的界面：录音中（红点与声波）、识别中（三点跳动）、已填字（绿勾）、未听清或异常（琥珀点）。
- 填字顺序：在 Android 13 及以上优先用无障碍输入连接写入当前光标；否则尝试把文字注入已找到的编辑框；若当时不在输入框，会先复制到剪贴板并提示「未检测到输入框，已复制到剪贴板」，并在约 5 秒内等到输入框后再补填一次。应用不会主动收起键盘或夺走焦点。
- 左侧键长按（`KEYCODE_782`）交给系统原样处理，本应用不接管。

## 隐私与网络

识别在手机本地完成：推理引擎是 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)，模型是 SenseVoice（仓库代码使用的是 `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17` 这一套公开文件）。主进程负责听键和填字；识别在独立进程 `:asr_worker` 中加载模型，推理结束后约 800 毫秒会结束该进程。

**不能说「完全不联网」。** 识别本身不访问网络，但下面这些操作会联网：

- 在应用内下载词典和模型时，会访问 Hugging Face 上的上述公开文件（应用会跟随重定向）。若该站点无法直接访问，下载可能失败；应用在失败提示和主页说明里提到了需要可用网络或开启 VPN，这只是下载路径问题，不是识别还要走云端。
- 点「GitHub 页面 ↗」会打开浏览器访问 sherpa-onnx 的模型 Release 页。

当前源码里没有看到其它上报或云端识别接口。麦克风录音只用于本次识别，模型文件保存在应用私有目录，不会随本仓库分发。

权限及用途：

- **麦克风**：采集 16 kHz 单声道音频，供端侧识别。
- **无障碍服务**（「本地语音服务」）：监听左侧独立键、显示状态小药丸，并把结果写入当前输入框。不开启则无法使用侧键和填字。
- **网络**：仅用于上述模型/词典下载，以及按用户点击打开 GitHub 页面。
- **震动**：可选的录音起止反馈，可在主页关闭。

清单里还声明了通知权限（`POST_NOTIFICATIONS`）和 `READ_LOGS`，但当前源码主流程里没有使用它们。

部分系统或 ROM 可能还会在后台限制无障碍服务或杀死进程。这些是否需要额外的自启动、后台或电池设置，本项目没有在其他机型上核实，因此这里不能给出通用步骤；若侧键突然没有反应，需要到对应系统的设置里自行检查「本地语音服务」是否仍处于开启状态。

## 构建

从源码编译需要：

- **JDK 17**（与工程的 `jvmTarget` / `sourceCompatibility` 一致）
- **Android SDK**：`compileSdk` / `targetSdk` 35；`minSdk` 26 只是可安装的下限配置，不是已测试范围
- 仓库已包含 Gradle Wrapper（`gradlew` 与 `gradle/wrapper`），不依赖仓库外的自定义脚本
- 安装到手机还需 **Android SDK Platform-Tools**（`adb` 在 `PATH` 中）

在仓库根目录执行：

```bash
./gradlew assembleDebug
adb install -r -d app/build/outputs/apk/debug/app-debug.apk
```

也可以使用仓库内的安装脚本（自动检测设备；若尚无 APK，会先调用同一套 `./gradlew assembleDebug`）：

```bash
./install-to-device.sh
```

本仓库不附带 APK。安装后仍须按「准备与使用」完成无障碍、麦克风和模型准备。

## 兼容性说明

已按我的一加 15R 使用习惯写死或强依赖的部分包括：

- 唤起方式依赖一加左侧独立键单击（`KEYCODE_781`）。没有这颗键、或键值不同的手机，将无法按同样方式使用；源码没有提供可配置的通用按键绑定界面。
- 状态小药丸固定在屏幕左缘、距顶部约 22% 屏高，尺寸按这台机器的侧键位置来排，其它屏比例或键位上可能错位。
- 查找微信输入框时，有一条针对 `com.tencent.mm` 和控件 ID `com.tencent.mm:id/bkk` 的路径；这是当前代码里的专用适配，微信改版后可能失效。其它 App 走通用的光标/节点查找，没有逐一适配，也没有兼容性清单。
- 优先填字通道要求 Android 13（API 33）及以上；更低版本会走无障碍节点注入等后备路径，这些路径在本项目中没有做跨机型验证。

未在其他机型、其它一加型号、第三方 ROM 或不同系统版本上做过验证，因此不保证可安装、可录音、可填字或侧键可用。也不提供识别效果或性能方面的对比数据。

## 核心实现要点

1. **一加左侧独立键作为开关（亮屏才响应）**
   仅在屏幕点亮且已解锁时处理左侧独立键单击；熄屏、锁屏时忽略。按一次开录，再按一次停止并识别填字；若未开口再按一次则静默关闭。
2. **侧键旁的四态小药丸**
   使用无障碍悬浮层（`TYPE_ACCESSIBILITY_OVERLAY`），`FLAG_NOT_TOUCHABLE`，触摸穿透。四种状态：录音中、识别中、已填字、未听清或异常。
3. **原位写入当前光标**
   优先 `AccessibilityInputConnection.commitText`；其后是无障碍节点注入，以及约 5 秒的焦点延迟补射。不主动收起键盘或夺走焦点。
4. **独立进程加载 SenseVoice**
   主进程保持较轻；`:asr_worker` 按需加载 INT8 或 FP16 模型，推理结束约 800 毫秒后结束进程。
5. **三卡片主页**
   只保留运行状态、语音模型（切换、下载、导入、打开 GitHub 页面）和震动反馈。
